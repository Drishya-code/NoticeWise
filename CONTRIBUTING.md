# Contributing to NoticeWise

Thanks for helping make public notices easier to understand. Contributions should keep the app focused, accessible, and careful about facts and privacy.

## Before opening a change

- Keep the API key on the server. Never put it in browser code, screenshots, or committed environment files.
- Treat notice text, images, and reader questions as untrusted input.
- Keep generated facts tied to the notice. Preserve the exact-quote check and flag uncertainty rather than guessing.
- Keep sample content clearly marked as sample content.
- Preserve keyboard access, responsive layout, and right-to-left support.
- Update the README and screenshots when user-facing behavior changes.

## Beginner-friendly contribution ideas

- Add a reviewed translation for one of the supported sample cards.
- Improve keyboard and screen-reader labels.
- Add a new notice category and a source-backed checklist.
- Improve the date display for more locales.
- Add synthetic notices to a future evaluation set, with expected dates and requirements.

## Pull requests

Describe the user problem, the behavior changed, and any provider or environment variables required. Do not include API keys, real private notices, or personal data in sample fixtures.
